# SNS運用会社

AIエージェント6人で運営するSNS運用会社。社長(あなた)の仕事は**最終判断だけ**。

## メンバー

| 担当 | 呼び出し方 | 責務 |
|------|-----------|------|
| 戦略責任者 | 「strategyに〜」「発信方針を決めて」 | 発信方針・方向性の設計 |
| リサーチ担当 | 「researchに〜」「競合を調べて」 | 競合分析・市場調査 |
| 企画担当 | 「planningに〜」「ネタ出しして」 | 投稿企画・ネタ出し |
| 編集担当 | 「editorに〜」「投稿を書いて」 | 投稿作成・改善提案 |
| マーケ担当 | 「marketingに〜」「note導線を作って」 | note導線・販売設計 |
| 秘書担当 | 「secretaryに〜」「進捗まとめて」 | タスク管理・進行管理 |

## 使い方

Claude Code でこのリポジトリを開いて、普通に日本語で依頼するだけです。

```
例:
「競合アカウントを分析して発信方針を決めたい」
 → リサーチ → 戦略の順で自動的に担当が動き、最後に選択肢が提示されます

「今週の投稿ネタを出して」
 → 企画担当が20本出し、推奨トップ5から選ぶだけ

「今の状況をまとめて」
 → 秘書担当がタスクボードと承認待ちを整理して報告
```

どの依頼でも、最後は「案A / 案B → どちらにしますか?」の形で返ってきます。判断だけしてください。

## ディレクトリ

```
.claude/agents/   6人の担当エージェント定義
docs/strategy/    発信方針・ペルソナ
docs/research/    競合分析・市場調査レポート
docs/planning/    投稿企画・ネタストック
docs/marketing/   note導線・販売設計
docs/tasks/       タスクボード・週次報告
posts/drafts/     投稿の下書き
posts/published/  公開済み投稿アーカイブ
```

## 最初にやること

1. 「まず発信方針を決めたい。ジャンルは◯◯」と依頼する
2. リサーチ → 戦略 → 承認、の流れでアカウントの土台が固まる
3. あとは「今週分の投稿を回して」だけで会社が回る
