# VoiceStudio ツール評価 — SNS運用での使いどころ(調査日: 2026-10-20)

> 担当: リサーチ(`research`)/ 対象: **会社共通のツール評価**(特定アカウントには紐づけない)
> 調査対象: https://github.com/debpalash/VoiceStudio (v0.5.7, 2026-10-20 時点の main)
> 情報源: リポジトリ本体(README・`docs/`・`backend/config/model_licenses.json`)を直接読んだ一次情報。Web上の評判・音質比較は未調査。

## 調査目的
- 音声クローン・ナレーション・吹き替え・文字起こしをまとめたOSS「VoiceStudio」を、SNS運用(動画・リール・音声コンテンツ制作)に使えるか判断する。
- 特に「商用利用できるか」「必要なPC」「日本語で使えるか」を確認する。

## 事実(データ・観察)

### 1. できること
| 機能 | SNS運用での用途 |
|---|---|
| 音声合成・音声クローン | 投稿動画のナレーション。自分の声をクローンすれば、録音しなくても読み上げ音声を作れる |
| ボイスデザイン | 文章で説明して架空の声を作る(キャラクター用ナレーション) |
| 動画吹き替え | 日本語動画を英語などに吹き替える(海外向けに展開する場合) |
| 文字起こし(WhisperX ほか) | 動画の字幕生成、音声メモ → 投稿の下書き化 |
| 音声入力ウィジェット | 話した内容をそのまま文字にする(ネタのメモ用) |
| オーディオブック・バッチ処理 | note記事を音声版にする、まとめて生成する |
| ローカルAPI / MCP | Claude Code から直接操作できる(将来の自動化に使える) |
| AI透かし | 生成音声に、聞こえない透かし(Meta AudioSeal)を自動で埋め込む |

### 2. 動作環境
| OS | ローカル動作 | 備考 |
|---|---|---|
| Mac(Apple Silicon M1〜M4) | ○ | macOS 13.3以上。GPUは自動で使われる |
| Mac(Intel) | × | 画面だけ動く。音声生成は別のマシンが必要 |
| Windows 10/11 | ○ | 高速に動かすには NVIDIA GPU が必要。なければCPUで動くが数倍遅い |
| Linux / Docker | ○ | — |

- 空きディスク容量は **約10GB〜** 必要。エンジンを追加するとそれぞれ数GB増える(例: CosyVoice 3 は約5.4GB)。
- メモリ16GBのMacでも動く(公式ベンチマークは M2 / 16GB)。ただし初回の生成は遅く(モデル読み込みに約8秒)、ブラウザなど他のアプリと同時に動かすとメモリ不足で落ちることがある。
- Python や FFmpeg はアプリが初回起動時に自動で入れる。事前の準備は不要。

### 3. 日本語対応
- 標準エンジン(OmniVoice)は646言語に対応しており、日本語も含まれる。
- 日本語対応が明記されているエンジン: **GPT-SoVITS**、**IndexTTS 2.5**、**Confucius4-TTS**、**VoxCPM2**、**MOSS-TTS-Nano**
- GPT-SoVITS は「日本語の自然さが優秀・高速」と書かれているが、アプリに内蔵されておらず、**別途サーバーを立てて接続する方式**。

### 4. ライセンス(最重要)
- **アプリ本体**は AGPL-3.0。商用利用も無料。
- **モデルのライセンスは別物**で、リポジトリ自体が `model_licenses.json` でモデルごとの状況を管理している。

| モデル | ライセンス | 同梱の審査結果 |
|---|---|---|
| **OmniVoice(標準エンジン)** | **CC-BY-NC(非商用)** + Higgs Audio 2 + Llama 3 | **非商用と明記** |
| OmniVoice-GGUF | CC-BY-NC-4.0 | 非商用 |
| NLLB-200(吹き替え時の翻訳) | CC-BY-NC-4.0 | 非商用 |
| OuteTTS | CC-BY-NC-SA-4.0 | 非商用 |
| CosyVoice 3 / VoxCPM2 / MOSS-TTS / dots.tts / Confucius4 | Apache-2.0 | 未審査(商用OKとは書いていない) |
| GPT-SoVITS | MIT | 未審査 |
| IndexTTS 2.5 | その他(独自) | 未審査 |
| Whisper 系(文字起こし) | MIT / Apache-2.0 | 未審査 |

- 「未審査」のモデルについても、リポジトリは「ライセンス表記は配布元のメタデータであり、許可を確認したものではない」と明記している。
- 非商用モデルを使うときは、アプリ内でライセンスへの同意が求められる。

## 考察
1. **標準設定のまま収益化アカウントで使うのはNG。** 標準エンジンのOmniVoiceは非商用ライセンス。収益化している(またはnote販売につなげる)アカウントの投稿に使えば、商用利用にあたる可能性が高い。商用で使うなら、Apache-2.0 / MIT のエンジン(CosyVoice 3、VoxCPM2、GPT-SoVITS など)に切り替え、配布元の利用規約をそれぞれ確認する必要がある。
2. **文字起こし・字幕生成はリスクが低く、すぐ使える。** Whisper 系は MIT / Apache 系なので、動画の字幕や音声メモの文字起こしから始めるのが安全。
3. **音声クローンは「自分の声のみ」に限るべき。** 他人の声のクローンは本人の許可が必須(README にも明記)。また、各SNSにはAI生成コンテンツの表示ルールがある(※この点は知識ベースからの推測で、今回は一次情報を確認していない。運用前に各プラットフォームの最新規約を確認すること)。
4. **PCの条件で使えるかどうかが決まる。** Intel Mac では音声生成ができない。Apple Silicon の Mac か、NVIDIA GPU を積んだ Windows が実用ライン。

## 戦略・企画への示唆(3点以内)
1. **まずは「文字起こし・字幕」用途で試す。** ライセンスリスクが最も低く、動画投稿の手間を減らす効果がすぐ出る。
2. **ナレーションに使う場合は、商用可能なエンジンと自分の声のクローンを組み合わせる。** 標準のOmniVoiceは評価・練習だけに使う。どのエンジンを本番に使うかは、試用で日本語の音質を比べてから決める。
3. **どのアカウントで使うかは別途決める。** 本レポートは会社共通の評価。特定のアカウントで使う場合は、そのアカウントのコンセプト(声のトーン・ターゲット)に合うかを戦略担当・企画担当が判断する。
