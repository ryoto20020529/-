# バズ投稿の型ストック(最終更新: 2026-07-05)

リサーチ担当が高エンゲージメント投稿の構造を分解して蓄積する。企画・編集はここから型を再利用する。

## 型の記録フォーマット
```
### 型名
- フック: 1行目の構造
- 展開: 本文の流れ
- CTA: 締めの行動喚起
- 効く理由 / 適するネタ
```

## 初期ストック(事例調査より)

### 型1: 逆張りフック型
- フック: 「みんな◯◯と言うが、実は逆」で常識を否定して止める
- 展開: 理由を3点、番号付きで短く
- CTA: 「保存して見返して」
- 効く理由: 認知的不協和でスクロールが止まる。ノウハウ系に強い

### 型2: 実体験ストーリー型
- フック: 「◯年前、△△だった僕が」と Before を晒す
- 展開: 転機 → 行動 → 結果(数字を入れる)
- CTA: プロフィール・note誘導
- 効く理由: 数字入りの変化は信頼と憧れを同時に作る。共感拡散が伸びる

### 型3: リスト網羅型
- フック: 「◯◯を7つまとめた。5個目は知らない人が多い」
- 展開: 箇条書きで即価値提供、1項目1行
- CTA: 「ブックマーク推奨」
- 効く理由: 保存率が高く、アルゴリズムがインプレッションを伸ばす

### 型4: 質問・巻き込み型
- フック: 二択や大喜利で問いかける
- 展開: 自分の答えを短く添える
- CTA: 「あなたはどっち?」
- 効く理由: リプライがエンゲージメント率を押し上げる。コミュニティ形成期に有効
