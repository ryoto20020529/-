# VoiceStudio インストール・試用手順(作成日: 2026-10-20)

> 担当: リサーチ(`research`)/ 対象: **会社共通**(特定アカウントには紐づけない)
> 前提資料: [ツール評価レポート](2026-10-20-voicestudio-tool-evaluation.md)
> 一次情報: VoiceStudio リポジトリの `docs/install/macos.md`・`windows.md`・`script.md`・`docs/engines/*.md`
> ※ この手順は社長のPCで実行するもの。クラウド環境からは社長のPCにインストールできないため、手順書として渡す。

---

## 0. 始める前の確認(3分)

| 確認すること | 確認方法 | OKの条件 |
|---|---|---|
| PCの種類 | Mac: メニュー → 「このMacについて」の「チップ」欄 / Windows: 設定 → システム → バージョン情報 | Mac は **Apple M1〜M4**。Windows は 10 / 11 |
| 空き容量 | Mac: システム設定 → 一般 → ストレージ / Windows: エクスプローラーのCドライブ | **15GB以上**あると安心(本体とモデルで約10GB、追加エンジン1つにつき数GB) |
| GPU(Windowsのみ) | タスクマネージャー → パフォーマンス → GPU | NVIDIA 製なら高速に動く。それ以外でも動くが遅い |

> **Intel Mac の場合はここで中止。** Intel Mac では音声生成ができない(画面しか動かない)。

## 1. インストール

### Mac(Apple Silicon)
**方法A: ターミナルで1行(推奨。ダウンロードしたファイルの検証と、セキュリティ警告への対処まで自動でやってくれる)**
```bash
curl -fsSL https://voicestudio.sh/install | sh
```

**方法B: 手動でインストール**
1. [Releases](https://github.com/debpalash/VoiceStudio/releases/latest) から `VoiceStudio-Electron-<バージョン>-mac-arm64.dmg` をダウンロード(**x64 版ではなく arm64 版**)
2. ダウンロードしたファイルを開き、`VoiceStudio.app` を「アプリケーション」フォルダへドラッグ
3. 初めて開くときに「開発元を確認できません」と出たら、Finder で **右クリック → 開く → 開く**
   (macOS 15 の場合: 一度ダブルクリックしたあと、システム設定 → プライバシーとセキュリティ → 「このまま開く」)

### Windows
**方法A: PowerShell で1行(推奨)** ※管理者として開かず、通常の PowerShell で実行する
```powershell
irm https://voicestudio.sh/install | iex
```

**方法B: 手動でインストール**
1. [Releases](https://github.com/debpalash/VoiceStudio/releases/latest) から `VoiceStudio-Electron-<バージョン>-win-x64.exe` をダウンロード
2. ダウンロードしたファイルを実行(管理者権限は不要)

> Cドライブの空きが少ない場合は、インストール時に別のドライブを選び、初回起動の設定画面にある「App environment → Change…」でも同じドライブを指定する。

---

## 2. 初回起動(10〜30分、回線速度による)
1. VoiceStudio を起動すると、Python や FFmpeg などの実行環境が自動でダウンロードされる。完了するまで待つ。
2. NVIDIA GPU がない Windows では、自動で軽量版(CPU版)が入る。その場合、画面に表示される「CPU プリセット」(KittenTTS / Supertonic-3 / PocketTTS など軽いエンジン)を選ぶ。
3. (任意)話者分離や大きなモデルを使う場合は Hugging Face のアカウントを作り、**Settings → API Keys** にトークンを登録する。

## 3. 試用メニュー(推奨順)

評価レポートの結論に沿って、**ライセンスリスクの低い順**に試す。

### ステップ1: 文字起こし・字幕(リスク低)
1. 文字起こしの画面で、手元の動画か音声ファイル(1〜3分)を読み込む
2. エンジンは標準の **WhisperX** のまま実行
3. 確認すること: 日本語の精度、専門用語の誤変換、字幕(SRT)を書き出せるか

### ステップ2: 自分の声のクローン(試用・評価のみ)
1. **Voice Cloning** を開く
2. **自分の声**を10〜20秒録音したクリアな音声を参照音声として追加する(雑音なし・一人で話しているもの)
3. Transcript 欄に、録音で話した内容をそのまま入力する(空欄だと生成のたびに文字起こしが走って遅くなる)
4. 投稿1本分くらいの文章(200〜300字)を入れて生成
5. 確認すること: 日本語のイントネーション、聞き取りやすさ、生成にかかる時間

> ⚠️ 標準エンジン(OmniVoice)は**非商用ライセンス**。ここで作った音声は**評価のためだけ**に使い、投稿には使わない。

### ステップ3: 商用で使えそうなエンジンの比較(本番候補を選ぶ)
**Model Catalogue → Engines** から、日本語に対応しているエンジンを1〜2個インストールし、ステップ2と同じ文章・同じ参照音声で比べる。

| 候補 | ライセンス表記 | 特徴 | 注意 |
|---|---|---|---|
| CosyVoice 3 | Apache-2.0 | 多言語対応・ワンクリックでインストールできる | 約5.4GB。Mac は Xcode Command Line Tools が必要な場合あり |
| VoxCPM2 | Apache-2.0 | 30言語に対応(日本語を含む) | 数GBのダウンロードが必要 |
| GPT-SoVITS | MIT | 日本語が自然で速いと書かれている | アプリに内蔵されていない。別途サーバーの構築が必要(難易度高) |

> 表のライセンスは配布元の表記で、VoiceStudio 側は「未審査」扱い。本番で採用する前に、配布元のモデルカードと利用規約を必ず確認する。

## 5. うまくいかないとき
- 公式のトラブルシューティング: https://github.com/debpalash/VoiceStudio/blob/main/docs/install/troubleshooting.md
- 遅いとき: 2回目以降の生成で判断する(1回目はモデルの読み込みで遅い)。ブラウザのタブを減らす。設定 → Performance で「GPU active」と表示されているか確認する。
- アンインストール(データは残る): `curl -fsSL https://voicestudio.sh/install | sh -s -- --uninstall`
