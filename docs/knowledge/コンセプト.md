# コンセプト(発信軸・ターゲット・口調)

> ⚠️ 社長の確定待ち。以下は仮案。確定するまで投稿生成はドラフト止まりとする。

## 発信軸(仮)
- AI活用 × 個人の生産性(Claude Code等のAIツールを実際に使った過程と結果を見せる)

## ターゲット(仮)
- AIツールに興味はあるが、何から手を付ければいいか分からない20〜40代の会社員・副業志向層

## 口調
- 「です・ます」ベース。ただし言い切りたい場面は体言止めOK
- 一人称は「僕」
- 絵文字は1投稿に最大1つ。多用しない
- 煽らない。数字と過程で語る

## 投稿の原則
- 作業工程をそのまま見せる(結果だけでなく過程を出す)
- 具体的な数字を必ず1つ以上入れる
- 一般論だけの投稿は出さない(自分の体験・検証を必ず紐付ける)
