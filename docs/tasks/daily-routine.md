# 毎朝7時の定例(ai-katsuyo)

対象アカウント: **ai-katsuyo(@yf8C21nnhFu4D2Y)のみ**。CPA事業には触れない(混同厳禁)。
実行時刻: 毎日 **07:00 JST(= 22:00 UTC)**。恒久Routineで駆動(セッション再接続でも消えない)。

## 毎朝の成果物(この順で社長に提示する)

### ① 前日投稿の分析
- `accounts/ai-katsuyo/posts/published/` から前日分の投稿を特定する。
- 反応記録テーブルに数値があれば、それを使って分析:
  - ブクマ率(ブクマ÷表示数)を計算し、**保存基準0.1%**と比較(超えたか未達か)
  - いいね率・リプ率、フックのどの要素が効いた/滑ったかを言語化
  - 使った型が機能したかを判定し、次に活かす示唆を1〜2点
  - 数値を `伸び投稿DB.md` に記録(基準を満たせばDB本体、満たさなければ候補表)
- **数値が未記入の場合**は、社長に「前日投稿の表示数・いいね・ブクマ」を尋ねる(コピペで答えられる形)。数値が来るまでは定性分析(フック・型・時間帯の妥当性)だけ先に出す。
- 前日に投稿が無い日は「前日投稿なし」と明記してスキップ。

### ② リサーチ結果(前日〜当日朝の収集)
- `/x-research` を対象=ai-katsuyoで実行し、公開Web経由でバズ投稿の型・事例を収集。
- 保存基準0.1%を厳守して `伸び投稿DB.md` / `viral-patterns.md`(型カタログ)を更新。
- 当日の要点を3行以内で要約(今日効きそうな型、新しく見つけた型、傾向の変化)。

### ③ 本日の投稿案(3案)
- `/x-post` を対象=ai-katsuyoで実行。①②の分析・最新DBを踏まえ、今日の最強の型で3案生成。
- コピペ用コードブロックで提示。推奨案+理由、投稿直後リプライ、推奨投稿時間も添える。
- 素材(社長の固有体験)が無ければ、直近の会話・作業ログから拾う。無ければ選択肢形式で1つだけ確認。
