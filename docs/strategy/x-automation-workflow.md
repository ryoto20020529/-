## 全体像

```
[毎日の定期実行(スケジュールトリガー)]
  1. リサーチ: Web調査で高エンゲージメント投稿の事例・型を収集
       → docs/research/viral-patterns.md に型を蓄積
  2. 企画: 型 × 発信の柱 からネタを選定
  3. 編集: 投稿を生成(フック→ボディ→CTA、A/B 2案)
       → posts/drafts/YYYY-MM-DD.md に保存
  4. 投稿: scripts/post_to_x.py で X API v2 経由で投稿
       → 承認モードに応じて「即投稿」or「社長承認後に投稿」
  5. 公開済みは posts/published/ へ移動、タスクボード更新
```

## 投稿モード(社長が選択)

| モード | 動き | リスク |
|--------|------|--------|
| A: 承認制(推奨) | 下書き生成まで自動。社長がOKした投稿だけAPI送信 | 事故ほぼゼロ。1日1回の承認作業が必要 |
| B: 完全自動 | 生成から投稿まで無人 | 文脈読み違い・炎上時に無人のまま拡散するリスク |

※ どちらのモードでも「いいね・フォロー・リプライの自動化」は行わない(2026年4月以降、API上Enterprise専用。かつ凍結リスクが高い領域)。

## 認証(正規ルート)

パスワードによるブラウザ自動ログインは**採用しない**(X利用規約違反・凍結リスク・認証情報漏洩リスク)。

代わりに X API の従量課金プランを使う。セットアップ手順:

1. @ryouto_arimun でログインした状態で https://developer.x.com にアクセスし、開発者アカウントを申請
2. プロジェクト/アプリを作成し、App permissions を **Read and write** に設定
3. 「Keys and tokens」から以下4つを発行:
   - API Key / API Key Secret
   - Access Token / Access Token Secret(Read and write権限で再生成)
4. Claude Code環境の**環境変数(シークレット)**に設定(チャットに貼らない):
   - `X_API_KEY` / `X_API_SECRET` / `X_ACCESS_TOKEN` / `X_ACCESS_TOKEN_SECRET`
5. 動作確認: `python scripts/post_to_x.py --dry-run "テスト"`

コスト目安: テキスト投稿 約$0.015/件 → 1日2投稿で月$1未満。

## 定期実行

Claude Codeのスケジュールトリガーで毎日1回実行する。トリガーのプロンプト(案):

```

1. researchでバズ投稿の型をWeb調査し viral-patterns.md を更新
2. planningでネタ選定、editorで投稿A/B案を posts/drafts/ に作成
3. [承認モードA] 社長に承認依頼を提示して終了
   [承認モードB] 推奨案を scripts/post_to_x.py で投稿し published へ移動

```

APIキー設定完了と投稿モードの承認後にトリガーを有効化する。

## 安全ルール

- 認証情報をリポジトリ・チャット・ログに書かない
- 1日の投稿上限: 3件(スパム判定・ネタ枯渇防止)
- 時事・炎上性の高い話題は完全自動の対象外(必ず社長承認)
- 毎週、投稿のインプレッションを振り返り、型ストックを更新する
