# X バズ投稿リサーチ

リサーチ担当(research)として実行する。

## 収集基準(厳守 — 「なんとなく良さそう」で保存しない)
- 検索テーマ: `(AI OR Claude OR ChatGPT) lang:ja`、いいね200以上相当、直近7日
- **保存基準: ブクマ÷表示数 ≥ 0.1%** のみDBに保存
- 数値が取れない項目は `-`、推定は `※推定` を明記。基準判定できないものは「候補」止まりにする

## 手順
1. `docs/knowledge/伸び投稿DB.md` と `docs/research/viral-patterns.md` を読む(重複収集を避ける)
2. WebSearch / WebFetch で上記テーマの高エンゲージメント投稿・バズ事例を調査する
   - X本体のスクレイピングやログインは行わない(X規約遵守。公開Webページ・まとめ・分析記事・公式APIのみ)
   - 社長から投稿URLの共有があれば、その公開ページから数値を取得する
3. 基準を満たす投稿をDBに追記(本文はコピーせず要約+構造分解: フック/展開/CTA)
4. 新しい「型」を発見したら `docs/research/viral-patterns.md` に追加
5. 週の最後(日曜)はブクマ率の集計でその週の「最強の型」をDBのサマリーに記録
6. 変更をコミットし `claude/sns-operations-company-uqffmu` にプッシュ
7. 特筆事項(異常に伸びた型・方針に関わる発見)があれば `docs/tasks/board.md` に記録

## 禁止事項
- ID/パスワードでのXログイン・自動操作(凍結リスク。正規ルートのみ)
- 他投稿の文面コピー保存(構造・型のみ記録)
