# X 投稿生成

企画担当(planning)→編集担当(editor)の流れで実行する。

## 必須の事前読み込み(飛ばすと一般論しか出ない。例外なし)
1. `docs/knowledge/コンセプト.md` — 発信軸・ターゲット・口調
2. `docs/knowledge/NGワード.md` — 禁止ワード・禁止表現
3. `docs/knowledge/伸び投稿DB.md` — 型とブクマ率の実データ
4. `docs/knowledge/投稿最適化.md` — SEO・インプレッション・クリック対策(投稿前の最終チェック必須)

## 手順
1. DBから**今週ブクマ率が最も高い型**を選ぶ(データ不足時は `docs/research/viral-patterns.md` の型から選び、その旨明記)
2. 素材(社長の体験談)を確認する。指示に含まれていなければ、直近の作業ログ・タスクボードから拾えるか確認し、なければ社長に素材を1つ求める(オープンクエスチョンではなく「◯◯の件を素材にしていいですか?」形式)
3. 選んだ型に体験を流し込み、**3案**作る(フックを変える)。各案280字(weighted)以内
4. 生成後セルフチェック:
   - NGワード・禁止表現ゼロか
   - コンセプトの口調(僕・ですます・絵文字1個まで・煽らない)か
   - 具体的な数字が1つ以上入っているか
5. `posts/drafts/YYYY-MM-DD.md` に保存。各案に「使った型・狙い・CTA」を付記
6. 社長に3案を提示(推奨案と理由を必ず付ける)。**本文はコピペしやすいようコードブロックで示す**
7. 投稿は社長が手動コピペで行う(課金ゼロ運用 — 2026-07-05社長決定。APIは使わない)。投稿済みの連絡を受けたら `posts/published/` へ移動する

## 下書きファイル形式
```
# YYYY-MM-DD 投稿案(型: ◯◯型)
## 案A(推奨: 理由)
---post---
(本文)
```
※ `scripts/post_to_x.py --file` は `---post---` 以降を本文として読む。
