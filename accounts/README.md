# accounts/ — アカウント別ワークスペース(混同厳禁)

このディレクトリ配下は**事業・アカウントごとに完全分離**する。各アカウントは独立した発信軸・ターゲット・口調・NGワード・投稿DBを持ち、**相互に混ぜてはならない**。

| フォルダ | 事業/アカウント | 発信テーマ | 状態 |
|---------|----------------|-----------|------|
| `ai-katsuyo/` | @yf8C21nnhFu4D2Y | AI活用 × 個人の生産性 | 運用中 |
| `cpa/` | 公認会計士(CPA)関連の別事業 | 会計士・会計領域 | 準備中(独立運用) |

## 絶対ルール(全エージェント・全モデル共通)

1. **投稿・リサーチ・企画の作業前に、対象アカウントを必ず確定する。** どのアカウントの作業か曖昧なら、着手前に社長へ確認する(推測で進めない)。
2. **あるアカウントの作業中は、そのアカウントの `<account>/knowledge/` だけを読む。** 他アカウントのコンセプト・NGワード・投稿DBを参照・流用してはならない。
3. **AI活用アカウントとCPA事業は無関係の別事業。** 口調・ターゲット・ネタ・投稿を一切混ぜない。片方の投稿にもう片方の話題を持ち込まない。
4. 成果物は必ず**対象アカウントのフォルダ配下**に保存する。ルート直下や他アカウントのフォルダに置かない。
5. コミットメッセージには対象アカウントを明記する(例: `[ai-katsuyo] 投稿案追加`、`[cpa] コンセプト草案`)。

## 各アカウントのフォルダ構成(共通)
```
<account>/
  account.md            アカウント情報(ハンドル・状態・プロフィール)
  knowledge/            発信軸・NGワード・投稿DB・最適化(このアカウント専用)
  planning/             投稿企画・ネタストック
  posts/drafts/         下書き
  posts/published/      公開済みアーカイブ
  assets/               アイコン・ヘッダー等の画像
```

会社共通の方法論(リサーチ手法・型カタログ・タスク管理・スクリプト)は `docs/` と `scripts/` に置き、アカポリ固有データは各アカウントフォルダに置く。
