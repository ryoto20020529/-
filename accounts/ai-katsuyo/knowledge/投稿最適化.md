# 投稿最適化チェックリスト(SEO・インプレッション・クリック)

投稿生成時に必ず適用する。x-postスキルの必須読み込みファイル。

## SEO対策(X内検索+Google検索)
- [ ] 狙うキーワードを**本文の前半**に自然に入れる(基本セット: Claude Code / AI活用 / 生成AI / 自動化)
- [ ] キーワードは1投稿1〜2個。詰め込まない(不自然さはCTRを下げる)
- [ ] ハッシュタグは**0〜1個**(多用はスパム判定・拡散低下。キーワードは本文に書く方が検索に強い)
- [ ] プロフィールの名前・自己紹介にも検索キーワードを入れる(名前はX内検索の対象)

## インプレッション対策
- [ ] 1行目フック: タイムラインで見えるのは**最初の約40字**。ここで止める(数字・意外性・断言)
- [ ] 2〜3行ごとに改行。スマホでの視認性を最優先
- [ ] **外部リンクを本文に入れない**(リーチが大きく抑制される。リンクや補足は投稿直後のリプ欄に)
- [ ] 投稿時間: 朝7〜8時 / 昼12時台 / 夜21〜22時(JST)のいずれか
- [ ] 投稿後30分はリプライに即返信(初速エンゲージメントがおすすめ表示を決める)
- [ ] 1投稿1テーマ。フォロワー外の初見でも単体で完結する内容にする

## クリック・フォロー転換対策
- [ ] CTAは1投稿に1つだけ(保存 / リプで質問 / プロフィールへ、のどれか)
- [ ] 手順・ノウハウ系は「保存推奨」の一言でブクマを明示的に促す
- [ ] 伸びた投稿には自分で補足リプをぶら下げる(リプ欄への導線=プロフクリック増)
- [ ] 固定ポストを必ず設定(プロフ訪問→フォロー転換の要)
- [ ] 投稿頻度は1日1〜3本。連投はミュートを増やす

## 投稿前の最終チェック
1. NGワード.md と突き合わせたか
2. 40字以内に最強のフックがあるか
3. キーワードが前半に入っているか
4. 本文に外部リンクがないか
5. CTAは1つか
