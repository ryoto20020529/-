# cpa/ — 公認会計士(CPA)関連の別事業(独立運用・混同厳禁)

> ⚠️ **この事業は AI活用アカウント(ai-katsuyo)とは完全に無関係の別事業です。**
> 発信軸・ターゲット・口調・NGワード・投稿DBはすべてこのフォルダ配下で独立管理します。
> ai-katsuyo の資料を参照・流用しないこと。逆も同様。

## 状態
- 準備中。コンセプト・ターゲット・口調・NGワードは社長のインプット待ち。
- 運用アカウント(ハンドル)未定 → 確定したら `account.md` に記録。

## 着手前に必要な社長インプット(戦略責任者が選択肢形式で確認する)
1. 発信テーマの具体(例: 会計士試験の勉強法 / 実務 / キャリア など)
2. ターゲット(受験生 / 実務家 / 経営者 など)
3. 口調・トーン(AI活用アカウントとは別に定義する)

インプットが揃ったら `knowledge/` にこのアカウント専用の コンセプト.md / NGワード.md / 伸び投稿DB.md / 投稿最適化.md を作成してから投稿生成に入る。

## フォルダ構成
```
cpa/
  account.md            アカウント情報
  knowledge/            発信軸・NGワード・投稿DB・最適化(CPA専用)
  planning/  posts/drafts/  posts/published/  assets/
```
